# MCP Servers

MCP (Model Context Protocol) servers provide AI coding agents with access to external tools and data sources. Each entry defines the server command, arguments, environment variables, and adapter compatibility.

## How to contribute

See [CONTRIBUTING.md](../CONTRIBUTING.md) for submission guidelines.
